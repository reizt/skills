# UI キャプチャへの注記

`scripts/mark.py` で、画像に 3 種類の注記を描く。どれも矩形の対角 2 点で位置を指定する。

| モード | 描くもの |
|---|---|
| `ellipse` | 矩形を内側に収める最小の赤い楕円。各半径は矩形の半幅・半高の √2 倍 |
| `rounded` | 矩形を囲む赤い角丸の枠 |
| `black` | 矩形の範囲を黒で塗りつぶす |

赤い線は矩形の外側に引くので、囲んだ中身にはかぶらない。線の太さは画像の短辺の 1/200（最小 4px）で、`--line` で変えられる。必要なのは ImageMagick（`magick`）だけ。

## 手順

### 1. 座標を決める

座標は元画像のピクセルで指定する。決め方は 2 通りある。

- Web 画面の要素なら、ブラウザで `getBoundingClientRect()` を取り、撮影時の倍率（`hires-capture` なら 2）を掛ける。目で測るより正確なので、取れるならこちらを使う。
- それ以外は、横 1000px に縮めた複製を Read して目で測り、`--ref-width 1000` を付けて渡す。元画像の座標への換算はスクリプトが行う。大きい元画像をそのまま Read すると、Claude に見える画像は縮小されていて座標がずれる。

```bash
sips -Z 1000 <元画像> --out <scratchpad>/ref.png
```

目で測るときは、対象より少し広めに取る。特に `black` は、端が数 px 足りないだけで文字の一部が見えてしまう。

### 2. 描く

```bash
~/.claude/skills/ui-marker/scripts/mark.py <元画像> <出力画像> MODE:X1,Y1,X2,Y2 [MODE:X1,Y1,X2,Y2 ...] [--ref-width 1000]
```

- 注記は指定した順に描かれ、後のものが上に重なる。黒塗りの上に赤丸を描きたいときは、黒塗りを先に書く。
- 出力先に元画像と同じパスを指定しない。測り直して描き直せるように、元画像は残しておく。

### 3. 確かめる

出力画像の縮小版を Read し、狙った場所を囲めているか、黒塗りで隠したい情報が端まで消えているかを確かめる。ずれていれば座標を直して、元画像から描き直す。

```bash
sips -Z 1000 <出力画像> --out <scratchpad>/check.png
```

### 4. 渡す

- PR や Issue に貼るときは `gh-image-upload` スキルで URL を発行する。
- クリップボードに入れてほしいと言われたら、次のコマンドを使う。

```bash
osascript -e 'set the clipboard to (read (POSIX file "<出力画像の絶対パス>") as «class PNGf»)'
```

## 注意

- `black` は画素を上書きするので、出力画像から元の情報は戻らない。ただし元画像は残るので、隠したい情報を含む元画像を人に渡したりアップロードしたりしない。
- 手で注記したい場合は `~/w/marker.html` をブラウザで開く。同じ 3 つのモードを、クリップボードからの貼り付けとドラッグで使える。
